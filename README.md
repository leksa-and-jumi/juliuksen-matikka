## Mitä opitaan / What you learn

1. 🐊 **Isompi vai pienempi?** – krokotiili syö aina isomman luvun (`<`, `>`, `=`)
2. ➕ **Plussalasku** kymppiin asti
3. ➖ **Miinuslasku** kymppiin asti
4. 🤝 **Kymppikaverit** – mitkä luvut tekevät yhdessä kympin
5. 🚀 **Yli kympin plussalla** – täytä ensin kymppi: 8 + 5 = 8 + 2 + 3
6. 🪂 **Yli kympin miinuksella** – mene ensin kymppiin: 13 − 5 = 13 − 3 − 2
7. 🕷️ **Hämähäkin hypyt** – satataulussa hyppy alas on +10 ja ylös −10: 24 → 54 on 24 + 30

Jokaisessa aiheessa: 📖 **Opi** (animoitu selitys, luetaan ääneen) → ✏️ **Harjoittele** (kuvat auttavat) → 🚀 **Haaste** (ilman apua). 🎯 **Päivän treeni** kertaa vaikeimmat tehtävät.

## Kehittäjille / For developers

```bash
npm install
cp .env.example .env.local   # täytä Convex-avaimet / fill in Convex keys
npm run convex:dev           # Convex dev (toinen terminaali / second terminal)
npm run dev                  # kehitys / development
npm run check                # testit ja tarkistukset / tests and checks
```

Ilman Convex-avaimia sovellus tallentaa edistymisen selaimeen. / Without Convex keys, progress is saved in the browser.
